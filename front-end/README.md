# Front-end Codecontenu

Le code de la boutique est dans `src/` (pages `src/routes`, composants `src/components`, logique `src/lib`)
et les icônes dans `public/`. Ces dossiers restent à leur place pour que l'aperçu et la publication fonctionnent.

- `/` : boutique · `/p/<produit>` : fiche + paiement Airtel Money · `/admin` : espace privé (aucun lien public).
- Variables : voir `.env.example`.
